# Periodic Table Database — freeCodeCamp Relational Database

A PostgreSQL database representing chemical elements and their properties.

## Features
- Elements, properties, and types tables
- Relational structure with constraints
- Query script for formatted output

## Technologies
- PostgreSQL
- Bash (lookup script)

## Usage
Run the Bash script to query element information.

## Credits
Project based on the freeCodeCamp Relational Database certification.
